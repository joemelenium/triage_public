# Test cases (vignettes)

These are fictional, synthetic test cases written by AI for testing a mock triage engine. The engine is a proof of concept and is not used for real patients.

- The cases do not describe real people.
- They are not medical advice and have not been clinically approved.

## Folders

- `dev/` and `holdout/` were written for this project.
- `external/` holds cases extracted from Semigran HL et al., "Evaluation of symptom checkers for self diagnosis and triage: audit study", BMJ 2015;351:h3480, published under the CC BY-NC 4.0 licence. Only the extracted facts are stored here. They are used non-commercially, with attribution to the original authors.
